# Personal Finance Manager Documentation

Personal Finance Manager is a web application that allows users to track income and expenses, analyze financial habits, set goals and budgets, and simulate future financial scenarios.

This file is the documentation index. Detailed topics are split into separate documents for easier reading and maintenance.
